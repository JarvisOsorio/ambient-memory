# Jarvis Nelson Osorio — About the Author

**Jarvis Osorio** is the short form of **Jarvis Nelson Osorio**, a technology entrepreneur and innovator based in **Miami Beach, Florida**. He builds local-first AI tools, writes on DAO institutional design, and is the author of *The Compliant Mind* (ISBN 979-8241483881) and *Breaking the Centralized Order: A Founder's Desk Handbook for DAO Institutional Design* (ISBN 979-8178385043).

Official site: https://jarvisosorio.com/about/jarvis-osorio/

## Open-source work

This repository, Ambient Memory, is one of four open-source releases by Jarvis Nelson Osorio:

- [ambient-memory](https://github.com/JarvisOsorio/ambient-memory) — local-first MCP memory layer (MIT)
- [mcp-pordego](https://github.com/JarvisOsorio/mcp-pordego) — MCP security scanner (Apache-2.0)
- [agent-session-scrubber](https://github.com/JarvisOsorio/agent-session-scrubber) (agentscrub) — transcript secret redaction (Apache-2.0)
- [agent-replay-lab](https://github.com/JarvisOsorio/agent-replay-lab) — TypeScript VCR for agent tool I/O (Apache-2.0)
